## 1. Showdown の定義（vendor a5df827、champions の mod も読んだ）

### 1.1 IKA-325 かなしばり（data/moves.ts と data/mods/champions/moves.ts）

```
disable.condition:
    onBeforeMovePriority: 7,                       // flinch 8 の下、挑発 5・ふういん 4・こんらん 3 の上
    // champions の mod が上書き
    onBeforeMove(attacker, defender, move) {
        if (!(move.isZ && move.isZOrMaxPowered) && move.id === this.effectState.move && !move.flags['cantusetwice']) {
            this.add('cant', attacker, 'Disable', move);
            return false;
        }
    },
    onDisableMove(pokemon) { ... pokemon.disableMove(moveSlot.id) ... },
twoturnmove:
    onMoveAborted(pokemon) { pokemon.removeVolatile('twoturnmove'); },
```

* port は `onDisableMove`（次のメニューで `MoveSlot.disabled`）だけを持ち、BeforeMove で止める半分が無かった。止まらなかったのは、
  溜め技の 2 ターン目（`twoturnmove` の `onLockMove` はかなしばりによらず撃たせる。IKA-316 の種 14 battle 68 turn 4）と、
  速いかなしばりの前に選ばれた技（前のターンに使った技をもう一度選んだ所に、先にかなしばりが入る）
* `cantusetwice`（M-C ではデカハンマーだけ）は止めない。`MoveSlot` の `effectState.move` は port の `Effect::move_id`

### 1.2 IKA-325 こんらんした溜め技の使い手 —— 溜め技の規則ではなく、固定した乱数の食い違いだった

```
confusion.onBeforeMove(pokemon):                   // data/conditions.ts、champions の上書きなし
    ...
    this.add('-activate', pokemon, 'confusion');
    if (!this.randomChance(33, 100)) return;
    ... 自傷 ... return false;
```

* オラクルの `installPolicy` は分母 100 の `randomChance` を命中の固定（`accuracy`）で答える。diff_turn・diverge_report は
  `accuracy: "hit"` なので、こんらんした側は**毎回**自傷する。port の `Budget.deterministic`（`pinned_policy`）は状態の判定を
  畳んで「動く」にしていたので、こんらんした側が動くターンはすべて黙って乖離していた
* 溜め技は関係ない: 普通のラスターカノンでも同じに外れる（`C:/tmp/ika325/probe_conf.py`、`tests/test_pinned_confusion_oracle.py`）
* 探索と生成の予算（`enumerate_status_checks`）は 33% の枝のままで、変わらない。直したのは固定した乱数（差分の道具とテスト）だけ

### 1.3 IKA-326 半減の実（data/items.ts、champions の上書きなし）

```
roseliberry.onSourceModifyDamage(damage, source, target, move):
    if (move.type === 'Fairy' && target.getMoveHitData(move).typeMod > 0) { ... target.eatItem() ... chainModify(0.5) }
chilanberry: if (move.type === 'Normal' && (!target.volatiles['substitute'] || ...)) { ... }

* `move.type` は `ModifyType` の後の型: スキン（フェアリースキン・スカイスキン・フリーズスキン・エレキスキン・ノーマルスキン・
  うるおいボイス）も、技そのものの変化（ウェザーボール・だいちのはどう等）も入る
* port のダメージ計算は変わった型で半減していたが、実を食べるかは技の元の型で決めていた。フェアリースキンのでんこうせっかは
  ロゼルのみを食べずに半減し続け、ホズのみ（ノーマル）は食べられていた。ウェザーボール（晴れで炎）とオッカのみも同じ

### 1.4 IKA-328 たいねつ（data/abilities.ts、data/conditions.ts、champions の上書きなし）

```
brn.onResidual(pokemon) { this.damage(pokemon.baseMaxhp / 16); }
