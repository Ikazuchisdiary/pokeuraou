9/26。ブランチ `ika-316-diff-tools-locked-choice`（master 2442df3 から切った）。一時ファイルは `C:/tmp/ika316/`。
出どころは IKA-309 §6。

## 1. 直し（道具だけ。src と port は触っていない）

IKA-309 と同じ原因: 固定された技（溜めの 2 ターン目・げきりん・はかいこうせんの反動）には Showdown がその技 1 つだけの
要求を出し、選択の番号をその中の位置として読む。5 本の道具は `pick.to_choice()`（4 枠の中の位置）をそのまま送っていた。

* `tools/diff_turn.py`: 断られた局を数える理由の文字列を `REFUSED_CHOICE` として置き、共有する（中身は IKA-309 と同じ
  "battle stopped: Showdown refused a choice"）。`showdown_choice` はそのまま
* `tools/diff_order.py`・`diff_speed.py`・`diff_replacement.py`・`diverge_report.py`・`diff_damage.py`: Showdown に送る選択を
  `showdown_choice(pick, request)` で作る。断られたら `skipped[REFUSED_CHOICE]`（diff_damage は `skipped_turns`）に数えて止める
  * diff_speed の `Report` には `skipped` が無かったので足し、`render` に出す
  * diff_replacement は、途中交代の比較（`_compare`）が断られたときも `REFUSED_CHOICE` に数える（従来の
    "choice rejected: ..." の数えはそのまま）
  * **diff_damage は `choice_errors` を見ていなかった**。断られたターンを空のログで比べ（"no damage" に数えていた）、
    局面が進まないので同じ手が毎ターン断られ、max-turns まで空回りしていた（直す前: 196 局で 1,513 回）
* 共通の置き場所は diff_turn のままにした。diff_replacement と diverge_report は既に diff_turn を import しており、
  残りの 3 本も tools/ から `from diff_turn import ...` で読める（tests の `load_tool` も tools/ を path に入れる）

## 2. 陽性対照と前後

「前」は直す前の写し（`C:/tmp/ika316/before/`）、「後」はこの枝の tools/。src・exe（この worktree で build）・sim-bridge は同じ。

  rng で局の頭に引くので同じ）。前後の単位を 1 つずつは突き合わせられない。diff_speed の前の 11 と diff_order の後の 2
