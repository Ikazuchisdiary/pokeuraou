# ladder の予算のテストが CI で 1 回落ちた件

## 要点

| 項目 | 内容 |
|---|---|
| 落ちたテスト | `tests/test_ladder_pool.py::test_a_filled_budget_ends_at_the_budget[ladder]`、608 行目 |
| 起きたこと | `stopped == "budget"` なのに `abandoned` が False |
| 原因 | 段と段のあいだで壁時計の予算が尽き、次の段を始めなかった。捨てた段が無いのは正しい状態 |
| 直したもの | テストだけ。`src/` の答えは変えていない |
| 再現 | 予算を 40〜327 ms で振った 291 回の読みのうち 1 回（予算 271 ms、`next_left_ms` = -0.105） |
| 陽性対照 | 予算を使い切らないまま段を止める不具合を入れると、直したテストが落ちる |
| 直した後 | 4 並列 × 50 回（各回 2 件）の失敗数は下の表 |

## 原因

`ladder.read` は段を始める前に、予測が残り時間を超えるかを調べる（`ladder.py` 777 行目）。
FILLS の読みは、残りが 0 を超えている限り段を始める。
残りが 0 以下なら、その段は始めず、`stopped="budget"` と `unfinished` を付けて終える。
この道で `abandoned` は付かない。始めていない段は捨てようがないためである。

`abandoned` が True になるのは、始めた段を予算の途中で捨てた場合だけである。
前の段が予算の終わりぎわに完了すると、次の段の開始時に残りが 0 以下になる。
この境目で、`stopped="budget"` かつ `abandoned=False` の読みができる。
LP の解き直しや段の後始末が数 ms かかるため、300 ms の予算でも起きうる。

IKA-396 が直した前の不安定さは、別の道（予算が尽きる前に段を止める道）だった。
今回の道は、IKA-370 の仕様（予算が尽きるまで段を始める）どおりの動きである。

## 再現

scratchpad の走査で、予算 40〜327 ms を 3 ms 刻みで 97 点、3 周した。
読みは 291 回で、うち 290 回は `(budget, abandoned=True)`、1 回が `(budget, abandoned=False)` だった。
その 1 回は予算 271 ms、読みの壁時計 271.14 ms で、`next_left_ms` が -0.105、完了した段は 1 つだった。
CI の失敗と同じ形である。

## 直し

テストの 608 行目を、次の形にした。

- `unfinished is not None` は常に求める
- `abandoned` が False のときは `next_left_ms <= 0` を求める

`abandoned` が False で残りが正のまま止まる読みは、このテストで落ちる。
読みの戦略と値は変えていないので、生成と対戦評価の局は変わらない。`src/` は触っていない。

## 陽性対照

`ladder.py` の段の開始判定に `at_stage == 1 or` を一時的に足し、2 段目を残り時間があるのに始めない不具合を入れた。
この状態で 2 件とも落ちた（`next_left_ms` = 280.8 で `<= 0` を満たさない）。
不具合は戻した。

## 回した回数

直したテストを 4 並列 × 50 回、計 200 回回した。1 回に 2 件（env と ladder）が入る。

| 並列 | 回数 | 失敗 |
|---|---|---|
| 1 | 50 | 0 |
| 2 | 50 | 0 |
| 3 | 50 | 0 |
| 4 | 50 | 0 |

全体の壁時計は 254 秒だった。
200 回で境目に当たったかは数えていない。0 件は、直しの前の再現率（291 回に 1 回）と矛盾しない範囲の結果である。
境目を確実に通す手段は用意していないので、直しの根拠は再現の 1 件と陽性対照である。

## 確かめていないこと

- CI の runner（GPU なし）での再現。手元の 1 回の再現で、CI と同じ形であることだけを見た。
- `abandoned=False` で `answer is None`（均衡が解けなかった）の道。この道は残り時間が正のまま `budget` になるので、直したテストは落ちる向きに働く。
- 他のテスト（`test_ladder_pool.py` の他の予算テスト）の同種の境目。
