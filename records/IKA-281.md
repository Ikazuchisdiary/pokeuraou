# IKA-281: refine のセルの選び方を「全セル深さ 2」を基準に比べた —— |深さ 2 − 深さ 1| の大きさは葉の値の 0.5 からの近さ（p(1−p)）と葉 2 本の食い違いで当たり、今の x_i・y_j は当たらない（無作為と同程度）。予算を使うなら「後悔（regret）が小さい手のセル」を先に深くする形が今の形より良く、神託にかなり近い

2026-09-25。担当 IKA-281（worker）。master a6d08b3 から切った `ika-281-refine-selection`（報告前に 61fb1aa を取り込み）。
本番の経路のコードは変えていない。足したのは測りの道具 `tools/refine_signals.py` とそのテストだけ。

## 2. 信号ごとの予測力（|深さ 2 − 深さ 1| に対して）

95% 区間は局面の束ねのブートストラップ（500 回）。AUC は |Δ| の上位 10% を当てる。「部分」は bern（下）を除いた偏順位相関。

信号: disagree = |葉 a − 葉 b|（深さ 1 のセル値）、spread = 偶然の枝どうしの葉の値の確率加重 sd、bern = d1·(1−d1)（深さ 1 の値の 0.5 への近さ）、
sens = x_i·y_j（今の形）、near_br = −(後悔_i + 後悔_j)、branches = 枝の数、*/gap = 信号 ÷ (後悔_i + 後悔_j + 0.001)、oracle = 真の |Δ|（正の対照）。

## 3. 予算ごとの選び方の比較

基準 = 全 refine 可能セルを深さ 2 にした行列の均衡。各選び方で選んだセルだけを深さ 2 にし、残りは深さ 1。
指標（局面の平均）: `exploit` = 読んだ戦略の組が**基準のゲームで**最善応答に対して失うものの両側の和（NashConv。均衡が複数あっても揺れない主指標）、
`err` = 根の値の誤差 |V − V_基準|、`TVx` = 行側の戦略の全変動距離。

選び方（同点は局面ごとに共通の無作為順）:

* **sens（今）**: x_i·y_j。支持の外は同点なので、予算が支持より大きいと残りは無作為になる
* sens>near-BR: x_i·y_j、同点は後悔の小さい順（今の形を予算まで伸ばす自然な形）。支持の外は near-BR と同じ
* sens*u: x_i·y_j·u_ij、同点は u（u = disagree / spread / bern）—— 感度 × 不確かさ（候補 2）
* near-BR: 後悔_i + 後悔_j の小さい順 —— 台に入りうる手（候補 3。純粋な局面では鞍点の行・列のうち値が鞍点に近いセル）
* u/gap: u ÷ (後悔_i + 後悔_j + 0.001) —— 不確かさを後悔で割る（候補 2 と 3 の組み合わせ）
* oracle*sens: 真の |Δ|·x_i·y_j（課題文の神託）、oracle/gap: 真の |Δ| ÷ (後悔 + 0.001)（もう 1 つの神託）
* random: null

w24 も同じ（今 0.0090、残りを葉 0.0069、ずれで選ぶ 0.0103）。

* **枝の選び方で得るものは小さい**: 今の 3 枝の誤差（根の exploit 0.0026）は、セル選びの誤差（0.04〜0.07）の 1/20
* 同じ費用で改善するのは「**落とした枝を正規化で消さず、葉の値で埋める**」（セル RMSE −32%）。確率 × 値のずれで選ぶのは良くならない
  （葉のずれは部分ゲームの値のずれを当てない。2 節の spread が効かないのと同じ）

## 5. IKA-254 への示唆

1. **最良優先の順位は「後悔の小さい手のセル」を軸にする**。第一候補は `bern/gap` = d1(1−d1) ÷ (後悔_i + 後悔_j + ε)
   （安い: 深さ 1 の行列と均衡だけで作れる）。予算が小さい（≤ 16）ところでは `sens>near-BR`（今の形 + 後悔の小さい順）と同程度で、
   32・64 で少し良い。葉 2 本の食い違い（disagree/gap）も同程度だが、サーバが平均しか返さないので本番では 2 本を別々に返す改修が要る。
   bern は本番の数からそのまま作れる
2. **感度 x_i·y_j は第一の鍵にしない**。|Δ| を予測せず、支持の外を順位付けられない
3. 読みは restricted（長方形）を保つなら、長方形の伸ばし方を行・列の後悔（と bern）で決める。予算を足せる形にする（今は passes で止まる）
4. 枝は今の 3 枝で足りる。変えるなら「残りを葉で埋める」（同費用で誤差 −32%）。確率 × 値のずれの選び方は入れない
5. ⚠ ここの数は**基準（全セル深さ 2、幅 8 の部分ゲーム）への近さ**で、強さではない。盤で確かめるのは IKA-254 の腕で
