# game-page-support: 試合経過の表示の直し（サポートの数え方・有利/辛い手・失敗する場の技の注記）

課題番号は調整役が後で振る。土台は master 5378018（game-transcript を取り込み済み）、IKA-395 の取り込み（eb627c1）も merge 済み。ブランチ `game-page-support`。
デザイン担当と組んで、実際の局のスクリーンショットで確かめた（最終は「可」）。

## 直したこと

| ユーザーの指摘 | 直し |
|---|---|
| 「均衡の確率 20%（2 位 / 64 通り）」の 64 は候補集合の大きさで、均衡で打つ手の数ではない | 順位の分母を、確率が 0.5% 以上の手（サポート）の数にした（「3 通り中 3 位」）。閾値はページの凡例に書く。候補の数は「ほかの候補 61 通りは確率 0.5% 未満（合計 <1%）で、均衡では打たない」の 1 行だけ。均衡に無い手を選んだ席は「均衡外の手」の札。相手の読みの表も同じ数え方 |
| 辛い相手の手（上位 3）は要らない | 表示から消した（記録の `hard` は残してある） |
| 有利になる相手の手を対で出す | 「選んだ手に対する相手の手」に 3 行: **一番辛い**（相手の全ての手の中）、**一番有利**（相手の均衡で打つ手の中）、実際の手（上の 2 つと別なら 3 行目）。差は読みの値との pt |
| 選んだ手が 2 か所（上の要約と場の行）に出る | 手の名前は場の各体の行だけ。閉じた要約は席ごとに 1 行の数字（均衡で打つ N 通り・相手の均衡の中で最悪/最善）と、最悪〜最善の帯と選んだ手の値の点の目盛り。場の席の枠の下に「均衡で打つ確率 26%（3 通り中 3 位）」の札。見出しは「この手番の読み」 |
| 失敗が決まっている手（IKA-395） | `narrow.dead_field_moves` を場の各体の手の行と、表の手の名前の後ろに小さな札で注記（候補は変えない）。5 種の言葉と意味はページ末尾の凡例 |

決めたこと: **辛い手は相手の全ての手の中、有利な手は相手の均衡の中**（デザイン担当の案。全列の最悪は、深く読んでいない列が浅い値のままなので、凡例に注記）。辛い/有利は、裏ありなら決定化の重みでの期待値（相手が裏によらず同じ手を打つときの値。読みの値＝保証値以上になる、前の記録どおり）。

## 記録に足したもの（`--transcript`、旗 off では何も変わらない）

`read_summary` に `p`・`q`（自分の混合と、相手の混合の全ベクトル。メニュー順）、`supp`・`oppSupp`（サポートの手と確率、大きい順）、`cols`・`vs`（選んだ手の、相手のメニューの全列に対する値）、`chosenEv`、`hardIn`・`bestIn`（相手のサポートの中の最悪と最善）を足した。閾値 `timematch.SUPPORT_MIN` = 0.005。前の形の記録（`p` が無い）は、順位だけ出す（数は作らない）。

## 確かめ（例の 3 局を打ち直して出し直した）

| 局 | 打ち直し | 記録・前の実行と |
|---|---|---|
| 全滅（L6 8 s 対 2 s、第 0 組 game 0） | 2 局 | 前の実行（`full2`）と 2/2 一致（時間の欄を除く）、各手番の value0 一致 |
| 判定打ち切り（同、第 1 組 game 0） | 4 局 | 前の実行（`on4`）と 4/4 一致 |
| 64 s 対 4 s（deep64v4 の第 1 組） | 2 局 | 記録と 2/2 一致（game 1: L64 の勝ち・10 ターン・全滅・手 18 個・各手番の value0・局の行が一致。3 回目の一致）|

サポートの数の突き合わせ（3 局・176 の混合、自分の混合と相手の混合の両方）:

- 全ベクトル `p`・`q` から数えた「確率 0.5% 以上の手の数」と、記録した `supp`・`oppSupp` の長さが 176/176 一致。名前を挙げた確率が、ベクトルの大きい順と一致（0 件の食い違い）。
- 局そのものが書いた Decision（`own`・`foe` の行。手番を読んだ席 = `pair % 2` の読みに当たる）との突き合わせ: 88 行、食い違い 0（0.5% 以上の行、確率の差 6e-5 以内 = 丸め）。
- 例: 全滅の局 T1 の席 0 は候補 64 通りのうち均衡で打つのは 3 通り（前の表示は「3 位 / 64 通り」）。3 局の自分の読みで均衡で打つ手は 1〜4 通り、候補は最大 64。

テスト: `test_the_pages_rank_is_among_the_moves_played_not_the_menu`（分母が 7 でなく 4）、`test_a_reads_summary_...`（`p`・`q`・`supp`・`vs`・`chosenEv`・`hardIn`・`bestIn`）、`test_the_page_says_which_field_moves_fail`（5 種の言葉、札が出る/出ない対照）。ruff 全体・関係テストは通る。

## 確かめなかったこと

- 失敗する場の技の札は、実際の局では 64 s 対 4 s の T7（席 1 のおいかぜ = 失敗するがふいうちは外す）でだけ見た。他の 4 種は単体テストのみ（判定は IKA-395 の担当）。
- 旧形式の記録から、サポートの数は出せない（`p` が無い。順位だけ）。
- 表は「均衡で打つ手」が多いとき（数十）の見え方は見ていない（例の 3 局は最大 8）。
