## 4. λ について M-C で分かったこと

* **searchValue を混ぜる λ は、M-C では上げられない。** M-C の searchValue は gen11L（M-B の葉）の深さ 1 で、検証の log loss 0.4842 は生徒（0.4514）より悪い。
  教師が生徒より弱いので、λ=0.7 は検証で +0.016 悪く、λ=0.3 でもターン 1 の AUC が −0.010。M-B の頂点 0.7 は、教師が同じ規則の前世代だったときの話
* **較正した深い値は、検証では教師として働く**（対象の行で教師の Brier 0.053 対 生徒 0.086。IKA-95 形で全体 −0.003）が、**盤では出荷と区別できない**
  （−4.4 [−14.8, +6.0]）。「検証の改善は盤に 1:1 で乗らない」（GENERATIONS.md「TD ターゲット」）の例がもう 1 つ増えた
* 課題の見立て（λ の最適は教師が生徒よりどれだけ賢いかで決まる）とは合う: 弱い教師（gen11L の深さ 1）は λ を上げると悪く、強い教師（較正した深さ 2）は
  λ=1 まで上げても検証は良い。ただし盤の得は見えない
* 混ぜた目標は長い学習に強く、AUC は 6 エポックで伸び続ける（0.8656 → 0.8680、ターン 1 は 0.661 → 0.681）。log loss は悪くなる（較正が崩れる）。盤では確かめていない

## 5. 推奨

* **出荷しない。** 既定（`train_value.py` の目標、`--td-lambda 0`）も変えない
* 次の世代（gen-1、mc0 が打つプール）で使うなら: 生成の後に d2r を mc0 で読み直し（生成 CPU の約 2%）、B10（IKA-95 形・λ=1）で学ぶ腕を 1 本だけ足して盤にかける。
  今回は教師が M-B の葉（gen11L）だったので、同じ規則の葉を教師にしたときの効きは測っていない
* searchValue の λ は M-C gen-0 では 0 のまま（教師が生徒より弱い）。gen-1 の searchValue は mc0（生徒の前世代・同じ規則）なので、そこでは測り直す価値がある
