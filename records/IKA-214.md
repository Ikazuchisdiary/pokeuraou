# IKA-214 はたきおとす・どろぼうがねんちゃくを見ない

課題: https://app.notion.com/p/3e64b8acaa6c8150bf80deaabf2ad13b

## 背景

IKA-208 で Trick・Switcheroo に Sticky Hold の免疫とメガストーンの判定を入れたが、持ち物を外す・奪うほかの
技と特性には入っていなかった。IKA-404 段 1c（大会の構築 400 戦）で、この乖離が 6 回出た。
Python の resolver は IKA-212 で消えたので、直すのは port（`rust/`）だけ。

## Showdown の規則（vendor a5df827、champions mod は下の技・特性・道具を上書きしない）

持ち物を外す道は、すべて `Pokemon#takeItem(source)`（sim/pokemon.ts 1851）を通る。`takeItem` は
持ち主に `TakeItem` を走らせ、答えるのは次の 2 つ。

- ねんちゃく（data/abilities.ts）。`breakable`。
  `if (!pokemon.hp || pokemon.item === 'stickybarb') return;`
  `if ((source && source !== pokemon) || this.activeMove.id === 'knockoff') { ...; return false; }`
  なので、持ち主が倒れていれば渡す。はたきおとす（`takeItem()` で source 無し）は名指しで止める。
  かたやぶりの使い手は破る。
- メガストーン（data/items.ts。Reg M-C は 81 個、すべて `onTakeItem`）。
  `return !item.megaStone?.[source.baseSpecies.baseSpecies]`。ここで `source` は持ち主（`runEvent` は対象を
  先に渡す）。`baseSpecies` はメガシンカ前の種なので、Garchomp-Mega も Garchompite を手放さない。
  フラエッテナイト・ニャオニクスナイトだけは `baseSpecies.name` を見る。
- `singleEvent('TakeItem', item, ..., receiver, giver)` は、道具自身のハンドラだけを呼ぶ（ねんちゃくは呼ばない）。
  受け取る側にも石の判定をする道。

## port の変更

- `rust/src/moves.rs`
  - `take_item`: Showdown の `takeItem(source)`。引数は持ち主・`source`（無し＝持ち主自身）・使用中の技とその使い手。
    石は持ち主の基底種で判定し、ねんちゃくは上の条件で止める（`-activate` 相当をログに出す）。
  - `thief_after_hit`・`hand_over`・`receive_item`・`after_receiving`: Thief・Covet・Magician・Pickpocket が共有する
    「受け取る側」の処理（石の拒否、choicelock、ひのみ・しろいハーブ、タネ）。`swap_items` の同じ処理を切り出した。
  - `after_hit`: knockoff・thief・covet の除去を差し替えた。`onAfterHit` は使い手が生きているときだけ
    （`if (moveData.onAfterHit && pokemon.hp)`）。持ち主が倒れていても外す。
  - `magician`・`pickpocket`: `after_move` から呼ぶ。pickpocket は `after_move_secondary_switches` の後、
    いのちのたまの前（攻撃側のたまを先に盗れば、たまの反動は起きない）。magician は反動・たまの後。
  - `apply_status_move`: corrosivegas。
- `rust/src/reg.rs`: `item_is_removable` は `mega_stone_stays`（基底種）を使う。
- `rust/src/resolve.rs`: `Turn::move_dolled`（身代わりが受けた相手。magician だけが読む）。`ability_handled` に
  magician・pickpocket を足した（`tools/port_gate_audit.py` が要求）。`commands.rs` は状態の書き出し・読み込み。
- `inert.rs`・`modelled.rs` を `tools/port_coverage.py --rust` / `--rust-modelled` で作り直した（magician・pickpocket が
  inert から出て modelled に入り、corrosivegas が modelled に入る）。

## 残り・見ていないこと

- symbiosis は未実装。`ability_handled` の「ターンから見える効果なし」の一覧に入っているので、port は黙って
  素通りする（Showdown は味方が道具を使った後に自分の持ち物を渡す）。道具を使う場所（きのみ・しろいハーブ・たすき等）
  すべてに hook が要るので、別の課題にする。
- ねんちゃくの `breakable` は、使い手の特性を「かたやぶり系」の一覧で見ている。ガスのバリアなど（`Neutralizing Gas`）、
  ふしぎなまもりの無効化、Ability Shield は見ていない。
- Pickpocket が反応する場面は、身代わり・倒れた持ち主・ねんちゃく・石のケースで確かめた。持ち主が
  交代フラグ（`switchFlag`・`forceSwitchFlag`）を立てている場面は、port の `pendingselfswitch`・
  `pendingforceswitch` で見ているが、Showdown との突き合わせはしていない。
- Python の resolver は IKA-212 で消えたので、Python 側の表と diff_node のずれの記録はない。
- `tools/agent_drift.py --check` は、この worktree に `data/models` が無く DRIFTED（asymmetry.py）になった。
  Python 側の変更が無いので無関係だが、data のある所では走らせていない。
