## 0. 結論

1. **深さ 0 から深さ 1 では、値は結果をよく当てるようになる。** 本番の評価モデル（value-mc4 の 2 本平均）で、対数損失は開いた局面で 0.0325（se 0.0045）、裏ありで 0.0151（se 0.0032）下がる。深さ 0 から深さ 1 への値の動きは、結果がほぼ全部を裏付ける（裏付けの傾き 0.98）。
2. **深さ 1 から深さ 2 では、結果を当てる力が増えない。** L6 の 8 s の読みで、開いた局面の差は −0.0042（se 0.0037）、裏ありで +0.0041（se 0.0033）。深さ 2 は値を平均 0.03〜0.04 動かすが、結果が裏付けるのは開いた局面で 6 割、裏ありで 4 割にとどまる。
3. **深さ 2 が当たりを良くするのは終盤の開いた局面だけ。** 手番 6 以上で残り 5 体以下の開いた局面（1,052 局面）では −0.0111（se 0.0049）。序盤と中盤では 0 か、悪くなる向き（手番 2〜3・残り 6〜7 体で +0.0335、se 0.0176）。
4. **裏ありのベイズの読みは、深くするほど読み手に不利な向きに偏る。** 深さ 2 の値の平均は結果より 0.026 低い。同じ局面を真の裏で読むと 0.007、開いた局面では 0.000。最初の深さ 2 の段（4×4 の長方形）で値が平均 0.029 下がり、後の段で 0.014 戻る。
5. **深さ 3 は、8 s では決着のついた局面でしか届かない。** 開いた局面の読み 3,889 のうち 747 が深さ 3 に届き、その 88% は値が 0.02 未満か 0.98 超。深さ 3 の当たりは、この測りでは判定できない。
6. **陽性対照**: 弱い評価モデル value-mc0 の 2 本平均では、深さ 0 から深さ 1 で対数損失が開いた局面で 0.087、裏ありで 0.039 下がる。この測りは深さによる当たりの差を検出できる。

改善のきっかけになりそうな仮説は §6 に置く。最も確かめやすいのは、評価モデルの学習の的（深さ 1 の打ち手どうしの局の結果）と、深い読みの前提（相手が深く読む）のずれである。

1. **深さ 2 の最初の段の下振れは、ほぼ全部が段の値の作り方から来る。** 段の値は「長方形の中の自分の行だけを使う戦略が、相手の全部の列に対して保証する値」である。最初の段は自分の行を 4 本に絞る。相手は長方形の外の列でも答えられる。この絞り込みの差（保証の値 − 全行列の値）は、裏ありで −0.033、開いた局面で −0.022。深さ 2 に読み直したセル自体による値の動き（全行列の値 − 深さ 1 の値）は +0.001 と −0.001 で、ほぼ 0 だった（§S2.3）。保証の値が片側の下界であることは、IKA-392 §3 が選出の読みで既に測っていた（両側から読むと和が 0.90）。

## S2.10 不具合: 深さ 3 以上の子が常に側 0 で読まれる

調整役の判断で、§S2.8 の席の差を不具合として扱う。本番化は別の課題で出す。

### どこか（origin/master 29efe09 の `src/pokeuraou/ladder.py`）

| 経路 | 場所 | 子の読み方 |
|---|---|---|
| 逐次（1 つずつ） | `_deep_children` の 1141 行 `read(reg, 0, crow, ccol, [Item(child)], [m], ...)` | 側 0 の行列 `m` を側 0 が読み、`got.value`（側 0 の保証の値）を親のセルに入れる |
| 逐次（子をまとめて、`BATCH_CHILDREN`、既定） | `_children_at_once` から `_kid_after` の 1628 行 `guarantee = ...col_ev[k].min()...` | 同じ。子の長方形の答えが側 0 の行で、全列に対する側 0 の保証を子の値にする |
| ワーカー（`SPLIT`・`PASSES`、IKA-375・380） | `_deep_split` → `_deep_child` → `_deep_children`、`_Pool.deep_passes` の子の段 | 上の 2 つと同じ関数を使う |

根の `read` は `side` を受け取り、側 1 なら行列を `-m.T` にして側 1 の保証を返す。子の読みにはこの `side` が渡らない。

### 鏡のずれと、手が変わる局面

§S2.8 の表のとおり。競り合いの開いた 50 局面で、側 1 の読みと席を入れ替えた読みの差は深さ 2 で 0.0000、深さ 3 の段で +0.0276（se 0.0057、最大 0.135）。最も打つ手が両席で違う局面は、深さ 2 の 16 / 50 から深さ 3 の 24 / 50 に増える。

### 修正案

`CHILD=seat` を既定にする。子を根の読み手の側で読み、読み手の保証の値を親のセルに入れる。根の値（読み手の保証）と同じ向きになり、席を入れ替えた読みが一致する。

* 今の旗は逐次の 1 つずつの経路だけにある。本番化には、子をまとめる経路（`_children_at_once`・`_kid_after`）と、ワーカーの経路（`deep_passes`・`_deep_split`）にも読み手の側を渡す必要がある。`_kid_*` は側 0 の行列 `kid.trial` を持つので、側 1 なら `-kid.trial.T` で長方形を作るか、側 1 の保証（`max(row_ev)` の符号を返したもの）を値にする。
* 子の表（`subshare` の `kid_key`）は子の段の名前で引く。読み手の側を鍵に足さないと、両席の読みが同じ表を使う対局（検討で両側を読むときなど）で別の値を取り違える。
* 別案の `CHILD=full`（子の全行列の値）は席に依らない。ただし子の全行列は深さの混ざった価格の値で、深さ 2 の根で避けた混ざりの楽観（IKA-362）を子に持ち込む。第一案は `seat`。

### 判定の形

1. 鏡のテスト: 席を入れ替えた読みと側 1 の読みが、深さ 3 と 4 の段でも一致する（`test_a_depth_three_childs_value_follows_the_switch` を、まとめる経路とワーカーの経路にも広げる）。旗が off の読みは今とビット一致する。
2. 同じ費用の速さ: 側 1 の子を `-m.T` で読む分の費用は変わらない見込みだが、ABBA で数えた時間と壁時計を比べる。まとめる経路を逐次に落とすと遅くなるので、まとめる経路のまま直す。
3. 対戦評価: 深さ 3 に届く予算（人と打つ時間の帯、単コア 4 s 以下の点から外挿する決まりに従う）で、修正後が修正前に弱くならないこと（SPRT(−10, 0)）。席 0 の打ち手は今は悲観、席 1 は楽観で読むので、席ごとの勝率も記録する。
