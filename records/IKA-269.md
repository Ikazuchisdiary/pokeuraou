## 2. 入れたもの（`beliefnode.py`、小さな関数だけ）

* `_reaching`: 側ごとに、その側の控えに届く汚れセルと、その届き方（その側の交代だけなら交代の行動、ほかは None）。
  `reaches_bench(..., {side: slots})`（葉が 2 つの対戦で既に使っている側ごとの判定）＋ その側が選ぶ交代を含む fold
  （`_choosers`）
* `_borrow`: 完成形 1 つの汚れセルを振り分ける。A は自分の貼った参照ブロック（`job.shared`）の span・fold を読む。
  B は先の完成形の充填の行を必要な分だけ抜き（`_subset`）、残りの隠れ枠を `_patched` で貼ったブロックを読む。
  B の fold は番号を付け替えないので解き直す。残りを返し、それだけを `_gather_dirty` で充填する
* `_entering`: 交代で入る枠と種族を、port と同じ規則で決める。**port は交代先を種族（または base species）で探し、
  いなければ party index を使う**（`transform::switch_names`、`resolve::involved`）。だから真の控えの Sylveon に
  交代するセルは、Sylveon を別の枠に持つ完成形ではその枠から Sylveon を出す
* 旧規則 `rules.patch_shares_side`（IKA-119 前の貼り方、IKA-141 の測る腕）のノードでは今までどおり全部を完成形ごとに解く
* `BeliefNode.redone` は実際に完成形ごとに解いたセル数

**最初の版は party index で鍵にしていて、`test_beliefnode` の 5 本が落ちた**（turn 1 の局面で completion 3〜5 の
10 セルずつ、最大 0.86）。上の種族の規則を入れて全部通る。この誤りはそのまま正の対照のテストに残した。

## 8. 別課題の候補

* **B のブロックの `_patched` が完成形の根を毎回符号化し直す**（encode +0.003 CPU 秒/局）と、`_borrow` の Python
  （belief +0.015）。完成形ごとに根の行を 1 回だけ作って使い回せば、この枝の上乗せの大半が消える見込み（合わせて約 1.6%）
* **B の fold を借りる**: 今は fold のセルを解き直している（fold の葉の番号を付け替えれば借りられる）。数は小さい見込み
* **交代先を種族で探す規則の意味**: 完成形の側では、真の控えの種族を持つ完成形はその枠から出す。これは今の定義
  （`_per_completion`）どおりで、この課題では変えていない。「相手から見てどの枠の誰が出るか」として正しいかは別の問い
