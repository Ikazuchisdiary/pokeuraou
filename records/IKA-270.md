# IKA-270: 葉の順位付け専用の安い予算を 5 つ測った —— 枝 2 本（refs2-b2）はメニューの 90.4% を残し葉を 0.45 倍にして生成を 1.08〜1.14 倍にするが、盤で今の順位付け（refs2）に SPRT H1 で負ける（52.0% ±1.5）。既定は変えない

2026-09-25。担当 IKA-270（worker）。master 1a54a12 から切った `ika-270-rank-budget`（報告前に master 24ffd3d を取り込み）。

**取り込んだのはこの記録と `tools/rank_fill_menus.py` の数え（セル/決定・葉/決定・葉/セルの列）だけ（ユーザーの判断、9/25）。** §1 のラベル（`rank_fill_budget`・`-one`・`-ties`・`-b<K>`）と `_menus` の変更はmaster に入っていない。コードは枝 `ika-270-rank-budget`（132a692）に残っている。

答えた問い: **葉の順位付け（`leaf_ranking`）の充填を、行列の予算（`Budget.matrix`）から偶然の枝を落とした予算で
解くと、メニューはどれだけ変わり、生成はどれだけ速くなり、盤で弱くならないか。** 形・道具・測り方は IKA-268 を踏襲した。

## 1. 入れたもの（既定の動きは変えていない）

* **`search.rank_fill_budget(label, budget)`**（新）: ラベルの名指す予算を、ノード自身の予算（行列の予算）から作る。
  `parse_rank_fill` の正規表現を `refs<N>(-fast|-one|-ties|-b<K>)?` に広げた（戻り値の形 `(応手数, fast)` は同じ）
  - 接尾なし: `budget` そのもの（同じオブジェクト。今までと同じ）
  - `-fast`: `Budget.fast`（IKA-268 のまま）
  - `-one`（候補 A）: 急所なし・必中・追加効果なし・状態の判定なし（最短）・速さの同着は正規の順で 1 つ・上限 1 枝
  - `-ties`（候補 B）: 速さの同着だけ数え、ほかは `-one` と同じく落とす（上限 16 のまま）
  - `-b<K>`（候補 C）: 行列の予算のまま、枝の上限だけ K（育てながら軽い枝から落とす。`-b1` は「最も重い 1 本」の形）
* `selfplay._menus` は `Budget.fast() if fast else budget` を `rank_fill_budget(rank_fill, budget)` に替えただけ。
  hidden-bench の `believed_ranking`、served の道も同じ `_menus` を通る（served・hidden で 1,200 局を打って確かめた、§3）
* **port（rust/src）は触っていない**。`Budget` の 7 つの設定（乱数・急所・命中・状態・追加効果・同着・上限）は
  すべて port に既にあり（`resolve.rs` の `Budget`、`commands.rs` の受け渡し）、Python の `Budget` から渡るだけで足りた
* `tools/rank_fill_menus.py`: 決定ごとに、各 fill の順位付けが充填したセルと port が返した葉（`len(encoded.species)`、
  IKA-268 の `fill.leaves` と同じ数え）を数え、表に「セル/決定・葉/決定・葉/セル」の列を足した
* ヘルプと docstring（`tools/selfplay.py`・`tools/pool_match.py`・`selfplay.py`）、`search.py` の既定の注記に結果

## 9. 別課題の候補

* **refs2-b4 の速さと盤**: 一致率 95.6%、葉 0.63 倍。b2 の結果からは速さの得は 1.04〜1.06 倍ほどの見込み
  （葉と子の時間が比例するなら順位付けの子 0.262 → 0.165、CPU −4% 前後）。盤で弱くならないかは測っていない
* **「残る手」の割合は盤の強さの代わりにならない**: b2（90%）が refs1（67%）より大きく負けた。落ちる手の均衡質量
  のほうが近いかもしれないが、それも b2（0.055）< refs1（0.169）で逆。メニューの比べ方に盤の結果と合う指標があるか
* **refs2-b2 のプールで学んだ葉は弱いか**（IKA-268 §8 の refs1 と同じ問い）。盤で弱いことと教える力が弱いことは別
