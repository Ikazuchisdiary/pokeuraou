## 数字

表・手順・分割は records/IKA-82.md §2 と同じ（同じ 12 本）。ここではスケジュールの差だけを抜く。

```
                               M-B（9/24、全プール、3 シード）          M-C gen-0（今回、2 シード）
                               単体 loss   x2 loss   |dp|              単体 loss   x2 loss   |dp|
  A 今のレシピ（ゼロから）       0.4199      0.4101    0.075             0.4625      0.4524    0.083
  B8 swa25（ゼロから）           0.4119      0.4097    0.034             0.4619      0.4602    0.033
  差（B8 swa25 − A）             −0.0080     −0.0004                     −0.0006     +0.0078
```

（M-B と M-C は分布も行数も違うので、列どうしの値は比べない。比べるのは各列の中の差。）

* **M-B での単体の改善（−0.008）は M-C で再現しなかった**（−0.0006、シード間の差 0.0006〜0.0011 と同じ桁）
* **x2 では B8 swa25 が +0.008 悪い。** SWA は 2 本を似せる（|dp| 0.083 → 0.033）ので、アンサンブルの上積みが A の −0.010 から −0.0017 に減る。M-B でも上積みは 0.0098 → 0.0022 と減っていて、
  単体の改善がそれを打ち消していた。M-C では単体の改善が無いので、減った分がそのまま負けになる
* 理由の見立て: M-C の学習行は 397,433 で M-B の約半分。ゼロからは ep3〜4 で検証損失が最小になり、B8 の後半（ep6〜8）は 0.472〜0.491 まで過学習する。
  SWA（ep2〜8 の平均）はそれを均しても、早期終了の ep4 の重みを越えない
* 温間の側は M-B の模擬と同じ向き: 「短く低く」が良い。W2（2ep・lr 5e-4）単体 0.4515 が最良で、W3（3ep・2.5e-4）0.4530、W4 EMA 0.4555、
  今のレシピの温間（WA、最良は ep2）0.4542。x2 では WA 0.4504・W2 0.4510・W3 0.4528

## 判断（検証の数字から。盤では確かめていない）

* **`ValueConfig` の既定は変えない。** 出荷は x2 のアンサンブルで、ゼロからの x2 は今のレシピが B8 swa25 より 0.008 良い。M-B の掃引で提案した既定の変更（B8 swa25）は、
  M-C では根拠が無くなった
* 温間始動のレシピは `train_value.py` の引数（`--init-from ... --epochs 2 --lr 5e-4 --keep last`）で渡せば足り、既定を変える必要は無い
* 盤（「W2 x2 対 S-A x2」）は、M-C のプールで 2 腕を対戦させる道具が無いので未実施（records/IKA-82.md §3）。盤で W2 が負ける・引き分けるなら、既定の話は「変えない」のまま

## 9/25 — 続き: 盤の後の結論

盤（records/IKA-82.md §4、IKA-259 の道具、生成と同じ条件）:

```
  温間 W2 x2 対 ゼロから S-A x2      53.5% ±2.4（Elo +24 [+8, +41]）、SPRT(0, 10) H1（795 対）
  原点 hp-share/w12 に対して         W2 x2 +229 [+211, +249]、S-A x2 +209 [+191, +228]、value-gen11L +151
```

* **`ValueConfig` の既定は変えない。**
  * 既定が決めるのはゼロからの学習。ゼロからの候補（B8 SWA25）は検証の x2 で今のレシピより 0.008 悪く、盤にかける理由が無かった。
    M-B の掃引で出した「既定を B8 SWA25 に」の提案は取り下げる
  * 盤で強かったのは温間始動の「短く低く、最後の重み」（2 エポック・ピーク 5e-4・`--keep last`）。これは `--init-from` と一緒に引数で渡すレシピで、
    ゼロからの既定とは別の話。既定に入れると、ゼロからの学習まで 2 エポックになる
  * IKA-86 の問い（学習率スケジュールを盤で確かめる）への答え: **スケジュールの差は、温間始動と組み合わせたときだけ盤で効いた**（温間 2ep 対 ゼロから今のレシピ 53.5%）。
    温間始動とスケジュールのどちらが効いたのかは、この盤では分けていない（温間を今のレシピで学習した WA x2 は盤にかけていない。検証では W2 x2 とほぼ同じ 0.4504 対 0.4510）
* 次の世代（gen-1）の学習は、`--init-from value-mc0.pt --epochs 2 --lr 5e-4 --keep last` を出発点にし、同じ形の検証（温間の 2〜3 案とゼロから）をしてから盤にかけるのがよい
