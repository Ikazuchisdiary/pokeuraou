## 2. 失敗する変化技は支配されない（`probe2.txt`）

| 発見 | Showdown の結果 | 関数の値 |
|---|---|---|
| **ふいうち** は相手が変化技を選んでいると失敗し、その変化技が失敗するものでもそう。まもるでも失敗。攻撃技（シャドーボール）を選ぶとふいうちが当たる | 失敗するおいかぜ → ふいうち `-fail`。シャドーボール → ふいうちで倒れる | `dead-but-dodges-sucker-punch` |
| **じだんだ** は直前の技が失敗していると威力 2 倍 | 失敗するおいかぜの次: 215→191（24）、成功する技の次: 215→202（13）、約 1.85 倍。テンパーフレア（`moves.ts` 19190）とメトロノーム（`items.ts` 4014）も `moveLastTurnResult` を読む | `dead-but-feeds-stomping-tantrum` |
| **アンコール**は失敗した技も直前の技として固定する | 次ターンにシャドーボールを選べない（`Shadow Ball is disabled`） | （失敗手の価値を下げる向きなので値には出さない） |
| **こだわり**（スカーフ）は失敗した変化技でもロックする | 攻撃技を選んだときと同じロック（別の技） | （同上） |
| **ターンの中で場が消える** | ひかりのかべ: 先に動く相手のかわらわり・サイコファングで壊れ、こちらの張り直しが成功。天気: 先に動く相手のあまごいで晴れが消え、こちらのにほんばれが成功。ディフォグは私のおいかぜを消さなかった。コートチェンジは未検証 | `dead-but-changeable` |
| **味方 2 体が同じ場の技**（2 体ともおいかぜ） | 通常は 2 体目が失敗。1 体目が相手のねこだましでひるむと 2 体目が成功 | 2 体目の slot が `dead-if-first-acts`（組は保険） |

支配の論理: ねこだまし（攻撃技）が失敗する手は「何もしない」で、任意の攻撃技に支配される。変化技は、(a) ふいうちをかわす（攻撃技と違う）、(b) じだんだの威力を上げる、(c) ターンの中で場が消えれば成功する、(d) 2 体の組は 1 体目が止まったときの保険になる、ので **他の手が常に上回るとは言えない**。

## 4. 関数 `narrow.dead_field_move`（`src/pokeuraou/narrow.py`）と使い方

`drop_dead_actions`・`rust/src/legal.rs`・`search.py` は変えない。関数は候補集合にも生成にも使われない。

```python
from pokeuraou import narrow
from pokeuraou.actions import side_actions

# pos: Position（transcripts の局面 `Position.from_json(decision["position"])`）、
# side: 0 か 1、action: SideAction（`side_actions(reg, pos, side)` の 1 つ。
#   記録の選んだ手 "move 4, move 1 2" は `next(a for a in side_actions(reg, pos, side) if a.to_choice() == text)`）
narrow.dead_field_move(reg, pos, side, action)    # -> None | 文字列（行動全体）
narrow.dead_field_moves(reg, pos, side, action)   # -> slot ごとの [None | 文字列]
```

返す値（`narrow.DEAD` などの定数もある）:

| 値 | 意味・表示の案 |
|---|---|
| `dead` | 張ってあり、消す・変える技もふいうちもじだんだ系も無い。「失敗する」と言い切れる |
| `dead-but-changeable` | 失敗するが、場の技・特性で先に消えれば成功しうる（「相手の先行次第」） |
| `dead-but-dodges-sucker-punch` | 失敗するが、相手のふいうちをかわす意味がある |
| `dead-but-feeds-stomping-tantrum` | 失敗するが、味方のじだんだ・テンパーフレア・メトロノームに効く |
| `dead-if-first-acts` | 同じターンの 2 体目。1 体目が止まらなければ失敗（保険の組） |
| `None` | 失敗の決まった場の技ではない（トリックルーム等を含む） |

行動全体の値は、どれかの slot が `dead` なら `dead`、なければ最初の slot の値。判定は局面だけを読む（相手の技・裏は記録の局面のまま。決定化された局面で呼べばその決定化での判定になる）。表示の担当は `tools/game_page.py` から上の形で呼ぶ（私は触っていない）。

## 5. 案 A（候補から外す）を採らなかった理由

- 効き目は見込みで 1.4 Elo 以下（失敗手で 1 回に失う勝率を最大 10% と仮定して 1 局 0.43 手番 × 平均の重み 0.05 × 0.1 ≒ 0.2%）。対戦評価で「弱くならない」を言うには、SPRT(−10,0) で約 7,100 局（真の差 0）、SPRT(−6,0) で約 19,700 局、±3 Elo の区間で 5.1 万局（勝率 0.5・引き分けなし・α=β=0.05）。SPRT(0,10) は H0 に約 7,100 局で、「+10 は無い」しか言えない。
- 支配の証明が完全でない（§2）。ふいうち・じだんだ・ターンの中の解除・保険の組で、外すと失う場合があり、条件 (ii)(iii) は真の局面でしか判定できない（決定化ごとに変わる）。実装は Python と Rust の 2 か所で、局が変わる。

## 6. 評価モデルの誤差の材料（IKA-394 へ）

失敗する手に均衡の重みが丸ごと乗る手番（重み 0.9 超）が 708 手番（候補 3 以上で 682）ある。失敗する手は「何もしない」に近いので、評価モデルがその手の行を他の手の行より高く（または横並びに）見積もっている。評価モデルの誤差の材料として、IKA-394 が使える（手番は `count.py` の `w > 0.9` で出る。局面は記録の `decisions[*].position`）。IKA-166 のねこだまし（41.6%）と同じ形だが、こちらはふいうちをかわす等の意味が残りうるので、全部が誤りとは言えない。708 は A の条件（ふいうち持ち・じだんだ持ちが場にいない）を満たす手番だけの数なので、そこでは失敗する手にふいうちをかわす意味も無く、重みが丸ごと乗るのは評価モデルの誤差と読める。
