## 1. Showdown の定義（vendor a5df827）

`sim/battle-actions.ts` の `hitStepMoveHitLoop`（857〜1010 行。champions mod は data/mods/champions/scripts.ts 428〜 に写しがあり、命中の部分 482〜511 は同じ形）:

```
for (hit = 1; hit <= targetHits; hit++) {
    if (damage.includes(false)) break;
    if (hit > 1 && pokemon.status === 'slp' && ...) break;
    if (targets.every(target => !target?.hp)) break;            // 的が倒れていれば振らずに止まる
    ...
    if (target && move.multiaccuracy && hit > 1) {               // 912 行
        let accuracy = move.accuracy;
        const boostTable = [1, 4 / 3, 5 / 3, 2, 7 / 3, 8 / 3, 3];

            if (!move.ignoreEvasion) { boost = clamp(的の回避, -6, 6);

            if (accuracy !== true && !this.battle.randomChance(accuracy, 100)) break;     // 外れたらそこで終わる
        }
    }
    ... spreadMoveHit ...
    if (!pokemon.hp && targets.length === 1) { hit++; break; }    // 使い手が倒れたら次の回の前に終わる

```

* **1 発目との違い**: 1 発目は `hitStepAccuracy`（IKA-231: 補正の chain を先に `modify`、段階は命中と回避を 1 つの整数の段にまとめて `trunc`）。2 発目以降は、命中と回避を別々に ±6 で切り、`boostTable` の**小数**を掛け・割る。`runEvent` の終わり（sim/battle.ts 929）は `relayVar === Math.abs(Math.floor(relayVar))` のときだけ `modify` を掛けるので、**値が整数でなければ補正（ふくがん・こうかくレンズ・はりきり・ゆきがくれ・ひかりのこな）は全部落ちる**
* **確率**: `randomChance(x, 100)` は `random(100) < x`（sim/prng.ts 115）。0〜99 の整数と比べるので当たる確率は `ceil(x) / 100`。例: 90 の技の命中 −1 は 1 発目 `trunc(90·3/4) = 67`（67%）、2 発目以降 `90 / (4/3) = 67.5` → **68%**。ふくがんの 90 は 1 発目 `modify(90, 5325) = 117`（段階 −1 で 87）、2 発目以降は段階 0 なら 117（100%）、段階 −1 なら 67.5 のまま（**ふくがんが効かず 68%**）
* 小数の残り: 90 の技では 100 未満で整数からずれる組は無い（−2 と回避 −4 の 126.00000000000001 など、100 を超える所だけ）。port は同じ順の f64 で計算する
* **外れたら止まる**: `break` だけ（`-miss` は出ない）。それまでの発は残り、`-hitcount` は当たった数。技は失敗扱いにならない
* **威力**（data/moves.ts）: トリプルアクセル 20005 行 `basePowerCallback: 20 * move.hit`（20・40・60）、`multihit: 3`、命中 90。ネズミざん 13613 行 `multihit: 10`、威力 20 固定、命中 90。トリプルキック 20037 行 `10 * move.hit`（10・20・30）だが champions mod で `isNonstandard: "Past"`（mods/champions/moves.ts 1078）、M-B・M-C の dump に無い
* **スキルリンク**（data/abilities.ts 4297）: `onModifyMove` で `multihit` の配列を上端に、**`multiaccuracy` を消す**（2 発目以降は振らない）
* **いかさまダイス**（data/items.ts 3454）: `onModifyMove` で `multiaccuracy` を消し、10 発技は `targetHits -= random(7)`（battle-actions.ts 881）。champions mod で `isNonstandard: "Past"`（mods/champions/items.ts 534）なので入れていない

## 6. port で何が動くか（g600、`C:/tmp/ika235/impact.py`、1 コア）

1,164 セルすべてと、使わないセルから無作為に 1,646（null 対照）。前 = 直す前の exe と master の dump、後 = この exe と新しい dump。

| 予算 | 使うセル: 枝の数が違う | 重みが違う | 同じ | 刈られ方（前→後、刈られない = exact） | 枝の平均 | 対照 1,646 | 秒（使うセル 前 / 後） |
|---|---|---|---|---|---|---|---|
| `Budget.matrix()`（上限 16） | 909 | 80 | 175 | 両方 exact 995・新たに刈られる 66・両方刈られる 103 | 4.05 → 6.30 | すべて同じ | 0.31 / 0.34 |

* 同じ 175・195 は、守られた・先に倒れた・的が 1 発で倒れるなど、2 発目の命中に届かないセル
* **両方とも刈られないセルでは、枝の数が減ったものは 0**（matrix で +0〜+12、exact で +0〜+56）。減ったセル（matrix 29、exact 多数）はすべて、後で上限に掛かったセル。上限のときは小さい枝から捨てて正規化するので、2 発目・3 発目で止まる小さな枝（1 本 0.02〜0.1）が先に捨てられる。matrix で新たに刈られる 66 セルは 1,164 の 5.7%
* 増えた枝の分だけ、使うセルの解きは matrix で約 10% 遅い（0.31 → 0.34 秒 / 1,164 セル）。exact は揺れの中。使うセルは g600 の 0.19% なので、全体では約 0.02%
