## 7. 別課題の候補（範囲の外。直していない）

* **門の `damageCallback`・`onHitField` は一度も働かない**: どちらも関数なので dump は値を書けず、`customHooks` に名前が載るだけ。`reg.rs` は key を見るので、この 2 つは死んだ項目。damageCallback の 7 技は IKA-213 で名前で実装済み（damage_callback.rs・moveinfo.rs）なので今は困っていない。onHitField の 4 技のうちくろいきり・ほろびのうたは名前で実装、コートチェンジ・おちゃかいは port に名前が無く、変化技の注記が出るかは確かめていない。門から外すか、`reg.rs` が `customHooks` も見るようにするかを決める。今回のテストは `HOOK_FIELDS` として別にしてある
* **`chloroblastRecoil` が門に無い**: battle-actions.ts 1382 で `mindBlownRecoil` と同じ反動。クロロブラストは champions で `isNonstandard: "Past"`（mods/champions/moves.ts 117）なので今は持ち主 0
* **dump にあって、port が読まず門にも無い field**（IKA-239 §8 の候補と同じ）: 今回のテストは「門 → dump」の向きだけを見る。逆向き（dump の宣言的な key ごとに、port の `Move` が読むか門が断るか）は別
* **てっていこうせん・ねごと・いびきの実装**: 門で断るようになった。M-C のプールと g600 には持ち主 0 なので急がない。M-B の事前分布では てっていこうせん 0.026%・ねごと 0.008%
