# IKA-410: 評価モデルの値が 1 ターン先で大きく覆る頻度

10/1。生成の局（gen-3、data/selfplay-mc3、value-mc2 が打った 40 万局）で、同じ席の続く 2 つの行動の手番の探索値の差 ΔV の
分布を出し（段 1）、大きく下がった例と無作為の例を打ち直して「裏が見えた・自分の混合・乱数・反省」に分けた（段 2）。
前例は records/selfplay-game-reads.md（T3 0.665 → T4 0.267）。駆動と出力は C:/tmp/ika410/、駆動のコードと表は
scratchpad/ika410/（当時のまま）。

## 要点

- 探索値（1 ターン先まで読んだ値）と、同じ局面の評価モデルの値（葉）が 0.2 を超えてずれる行動の手番は 9.4%（0.1 超は 28.5%）。
  2 万局・33 万（手番 × 席）で数えた。打ち直した無作為の 197 例でも 9.1%（±4.0%）で同じ。
- ずれの向きは平均では 0（片寄りなし）。ずれた手番の局の結果は探索値の側に合う。探索が葉より 0.2 以上低い手番は、
  葉 0.580・探索 0.277・実際の勝率 0.273。反対向きは葉 0.422・探索 0.725・勝率 0.727。
- 大きく下がった手番（ΔV < −0.3、決定の 4.4%）を分けると、平均 −0.445 のうち次のとおり。
  - 反省（評価モデルの値 → 次の局面の探索値）: −0.215。約半分
  - 乱数: −0.119
  - 自分の混合から引いた手: −0.094
  - 行列の予算の差: −0.013
  - 裏が見えた: −0.012
  - 相手の手が読みと違った: +0.002
- 反省が大きいのは残りの体が少ない終盤。2 対 2 で |ずれ|>0.2 が 25.2%、1 対 1 で 17.6%、4 対 4 では 6.1%。
- 反省の大きい 12 局面から同じ設定で 150 局ずつ打つと、12 局面すべてで探索値の方が実際の勝率に近かった。
  例: 葉 0.838・探索 0.016 の局面で勝率 0/150。
- value-mc3（gen-3 で学んだ次の世代）で同じ手番を解き直すと、ずれは小さくなる。大きく下がった例で平均 |反省| が
  0.215 → 0.164（対の差 −0.051 ±0.017）、無作為の例で 0.072 → 0.064（−0.008 ±0.009）。ただし value-mc3 はこの局で
  学んでいる（標本内）。

## 言葉

| 言葉 | 意味 |
|---|---|
| 席の値 | 席 0 は記録の `searchValue`、席 1 は 1 − `foeSearchValue`（どちらも席 0 の単位で記録されている）。その席の勝率の読み |
| d0・d1 | 同じ局の続く 2 つの行動の手番（間に交代の手番・とんぼがえりの手番があってもよい） |
| ΔV | 席の値の d1 − d0 |
| 葉 | 評価モデル（value-mc2）の値。本当の局面（両側の裏が分かっている局面）で引いた |
| 反省 | 葉と、その局面の 1 ターン先の探索値（生成の設定）のずれ。探索値 − 葉。負なら評価モデルが高く見すぎていた |
| r | 記録だけから出した反省: 記録の席の値 − 本当の局面の葉。打ち直さなくても出せる |

## 段 2: 打ち直して分ける

### 方法

- 例の選び方: 段 1 の組から、ΔV < −0.3 の 12,744 組のうち 200 組と、全体から無作為に 200 組を選んだ（種 410、398 局）。
- 打ち直し（scratchpad/ika410/stage2.py）: 生成と同じ設定で `poolplay.generate_pool(indices=[局番号])` を CPU で回した。
  - 設定: seed 40002、value-mc2 x1、幅 12、裏非公開、q-nocover・q-mc2、選出は C:/tmp/ika402/store-gen の写し
  - 生成と同じコード: Python は 4468a48（生成の記録の `engine.commit`）、port の exe は rust/ が 4468a48 と同じ C:/tmp/ika401/wt の exe
  - 記録との照合: 各決定の種類・ターン・選んだ手、両席の値、手ごとの混合が 1e-4 以内のとき、その決定を一致とした。d1 まで一致した例だけを使った。
- 候補集合の並び: 最初の打ち直しは 163/400 しか一致しなかった（C:/tmp/ika410/diag.py）。
  - 原因: 候補集合の集合と混合は記録と同じで、並びだけが違っていた。生成は葉を GPU で引いて順位を付けており、CPU では同点に近い候補の順が入れ替わる。手は混合から「並びの何番目か」で引くので、同じ混合でも別の手を引く。
  - 直し方: 行動の手番の候補集合が記録と同じ集合のときだけ、記録の並びに置き換えた（`spy_menus`）。混合・値の照合はそのまま。
  - 結果: 一致は 396/400。置き換えた手番 2,127、元から同じ並び 1,428。前例の局（3 手番が並びだけ違った）でも 3 / 6 と数えた。
- 前例の局の再現（陽性対照）: 0.665 → 0.574（裏）→ 0.553（自分の手）→ 0.554（厳密な升目）→ 0.541（引いた枝）→ 0.267（T4 の探索）を、記録どおり再現した。
- 比べが落ちることの対照: 記録の 3 つ目の決定の値を +0.01 ずらすと、不一致（`first_diff` = 2）になる。
- 分け方（席の単位、続けて足すと V1 − V0 に戻る）:

| 項 | 中身 |
|---|---|
| (a) 裏が見えた | d0 の裏の決定化ごとの値 v_k = x G_k y_k を、d1 までに見えた分で条件づけた信念で平均し直した差 |
| (a') まだ見えない裏 | 本当の裏の決定化の値 − 条件づけた信念での値 |
| (b') 相手の手 | 相手が実際に打った手の列 − 自分が読んだ相手の混合 |
| (b) 自分の混合 | 自分が引いた手の升目 − 自分の混合 |
| (c0) 予算 | 行列の予算の升目 → 厳密な予算の升目（`Budget.exact`、止まりも含む） |
| (c) 乱数 | 厳密な升目の期待 → 引いた枝の葉 |
| (d) 反省 | 引いた枝の葉 → d1 の探索値（本当の裏の決定化） |
| (e) d1 の信念 | d1 の本当の裏での値 → d1 の信念での値（記録の値） |
| (d*) 手番の反省 | d1 の局面そのものの葉 → d1 の探索値。間の交代の手番を含まない |

## 言えること・言えないこと

- 言える: 生成の局では、行動の手番のおよそ 1 割で、評価モデルの値と 1 ターン先の探索値が 0.2 を超えてずれる。
  - 向きの片寄りはない。
  - ずれたときの局の結果は探索値の側に合う（2 万局で 0.273 対 0.277、0.727 対 0.725）。
  - 大きく下がった手番の半分は、このずれ（反省）。残りは乱数と自分の混合で、裏が見えた分は小さい（−0.012）。
  - 終盤の拮抗（2 対 2・1 対 1・葉が 0.3〜0.7）で多い。
- 言えない:
  - 局の結果が探索値に合うことは、生成の打ち手（value-mc2 の深さ 1）の自己対戦で見た勝率。強い打ち手どうしでも同じかは測っていない。
  - 反省の大きい局面の「形」は、記録から取れる特徴（ターン・体の数・場の状態など）でしか分けていない。決着の形（次のターンで倒し切れる、など）は確かめていない。
  - value-mc3 での減りは標本内。
  - 段 1 の ΔV と段 2 の分解は、行動の手番どうしの組だけを見ている。最後の行動の手番から局の終わりまでは入れていない。

## 別課題の候補

- 信念が T1 → T2 で条件づけと違う形に変わる（396 例中 3 例）。
  - 3 例とも、相手のフラエッテ（えいえんのはな、`floetteeternal`）が T1 にメガシンカしていた。
  - 裏の決定化の数が、T1 の 6（残り 4 体から 2 体）から T2 で 10（5 体から 2 体）に増えた。もう 1 例は、裏が 1 体見えた後に 4（本来は 3）。
