* 開いた 24 s で B が速くならなかったのは、port の `fills` の答えが 12% 遅くなり（352 → 395 ms / ノード秒）、推論サーバの往復 1 回が 5.5 → 6.4 ms に延びたため。CPU の平均は 83% → 82%（§6）で、ワーカー過程の Python が空けた分（4.8 → 3.0 コア）の大半を port（5.4 → 6.7〜6.9 コア）と推論サーバ（1.16 → 1.30 コア）が取った。開いた 8 s・裏あり 8 s ではこの取り合いが小さく、`fills` はむしろ速かった。24 s の深い段の読みで何が詰まっているかは切り分けていない（§7 の 2）。

## 7. 残り・別課題の候補（効き目の見込みの大きい順）

1. **B2: 推論サーバの口を port に**（見込み 1.03〜1.06 倍。次の段、§7.1）。
2. **開いた 24 s で速くならない理由を切り分ける**（見込み: 24 s 以上で 1.05〜1.10 倍が取れるかの判断。中）: B で port の `fills` が 12% 遅く、推論サーバの往復が 16% 延びた。同じ条件で 2 組目の ABBA、port の `fills` の CPU とスレッドの配置（どの論理コアの対で port と推論サーバが並ぶか）を見る。
3. **深いセルの子の LP と段の LP も port に**（見込み: ワーカー過程で 7 ms / ノード秒、読み手で開いた 24 s の CPU の 35%。小〜中）: `lp` の口はベイズ型も束で全部ビット一致したので、`_kids_fill`・`_kid_solve`・`_answer` に同じ口を付けるだけ。読み手は巡ごとに 1 往復になるので、巡の子をまとめて解く形に。
4. **HiGHS 1 回の固定費**（見込み: port の LP の時間の 1〜3 割。中、局が変わる）: 12 × 13 ほどの LP に 121 µs。presolve を切る・両 LP を 1 回で解いて双対から相手の混合を取る、は答えが scipy と変わるので、候補集合の一致の要件と局面集の損失で判定する別の課題。
5. **span の塊を送り返さない**（見込み: `solve_subs` の 9.8 ms / ノード秒の半分と `folds` の入力 0.5〜0.9 MB / ノード秒。小）: port が `fills` の span を塊の間持つ（状態を持つ）か、B2 で消える。
6. **CI で ubuntu の build を確かめる**（最初の取り込みの後）: HiGHS を cmake と g++ で作る道はこの機械（Windows）でしか通していない。

### 7.1 次の段（B2）の手順と見込み

1. **推論サーバの口の約束を固定する**（Python の `RemoteValue`・`RemoteQ` の制御行と共有メモリの配列、行の塊の組み方）: 数えた時計の読みで、推論サーバへの依頼（行・順・塊の大きさ）を捕まえて束にする（専有なし、1 分）。
2. **port から推論サーバへ**（Rust、推論サーバの口 800〜1,500 行）: `fills` の後、port が符号化した葉をそのまま推論サーバに送り、値を受けて畳み・LP をし、部分ゲームの値と注記だけを Python に返す 1 往復の命令（`fillsSolved` のような名前、既定 off の旗）。`STACK` の塊は今の Python と同じ行の並びで組む。Python の `pending_payoffs`・`score_stacked`・`solve_subs` の 3 往復が 1 往復になり、span の塊も葉の配列も Python を通らない。
3. **確かめ**: 推論サーバへの依頼のバイトが Python の道と同じ（捕まえた束）。hp-share と学習した葉で段・数えた仕事・注記がビット一致。数えた時計 1・16 スレッド 7/7。故障注入（行の順をずらす、塊を 1 つずらす）。ABBA 16 スレッド（開いた 8 s・裏あり 8 s・開いた 24 s）。局面集の損失。生成のスモークテスト 48 局。
4. **見込み**: 動かせるのは Python の `fill_encoded_many`（18）・`unpack`（14）・推論サーバの口（25）・`portlp`（15）とパイプの往復で、1 ノード秒あたり 70〜90 ms（ワーカー過程の時間の 5〜6%）。倍率 1.03〜1.06 倍（開いた 24 s は §7 の 2 しだい）。
5. **専有の見込み**: スモークテスト 1 分、数えた時計 2 分、ABBA 開いた 8 s 3 分・裏あり 8 s 3 分・開いた 24 s 7 分、損失 5 分、合計 約 21 分。
