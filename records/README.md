# records/ —— 作業の記録

9/24（IKA-228）から、作業の記録はここに置く。`TODO.md` は 1.26 MB・138 節になり、並行の枝がみな
末尾に追記するので取り込みのたびに衝突していた。`TODO.md` は凍結して残す（中身は書き換えない。
「TODO.md「9/24 — IKA-NNN」」という参照はそのまま有効）。

## 置き方

* **1 課題 1 ファイル**: `records/IKA-NNN.md`。見出しは `# IKA-NNN: <何をして何が分かったか>`、日付は本文の
  先頭に書く。同じ課題の続きは同じファイルの末尾に `## 9/25 — 続き: …` の節で足す
* **課題をまたぐもの**（調整役の記録、複数の課題の取り込みの順など）: `records/YYYY-MM-DD-<名前>.md`
* 書くもの・書き方は `TODO.md` の節と同じ（日本語、測った数と対照、機械時間、別課題の候補）。LF
* 課題の管理（何をやるか・誰がやるか）は Linear。ここは「やったことと分かったこと」だけ

## 探し方

```
grep -rn '<語>' records/ TODO.md GENERATIONS.md
```

測る前に、同じ問いを前に測っていないかをここで探す。
