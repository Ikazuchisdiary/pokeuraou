## 3. 入れたもの

port のダメージの入口を先に数えた。`Turn::deal_damage` を呼ぶところは 20 か所（moves.rs 17・resolve.rs 2・level_struggle.rs 1）。
攻撃技のダメージ（`from_move = true`）は moves.rs 2062 の 1 か所だけで、残り 19 か所はすべて `from_move = false`。HP を直接
減らすのはみがわりの HP（moves.rs 3362）だけで、これは Showdown でも `directDamage`。だから入口の `deal_damage` 1 か所で止めた。

* 新しい `rust/src/magic_guard.rs`
  * `passes_magic_guard(reason)`: 技以外でもマジックガードを通すもの。`confusion`（effectType 'Move'）と `strugglerecoil`（directDamage）
  * `stops(turn, side, slot, from_move, reason)`: `!from_move`、通すものでない、持ち主の特性が `magicguard`
* resolve.rs `deal_damage`: 本体の前に `if crate::magic_guard::stops(...) { return Ok(0); }`（3 行の挿入。既存行の書き換えは 0）。
  止めたときは HP も `hurt_this_turn` も変えず、きのみの確認もしない（Showdown で `Damage` が `false` を返したときと同じ）
* main.rs に `mod magic_guard;`、`tools/port_coverage.py` の `PORT_ENGINE_FILES` に `magic_guard.rs`。`magicguard` は元から
  modelled.rs の `ability_is_modelled` にあるので、modelled.rs と inert.rs は変わらない（`port_coverage --check` が通る）
* 天気・やどりぎ・状態の残りの数にある `magicguard` の飛ばしは残した（動きは同じで、書き換えを減らすため）
* 特性を消す・替える効果（いえき・かがくへんかガス・なやみのタネ・スキルスワップ等）は port にもともと無い。`mon.ability` を
  そのまま見る点は、前からある 3 か所の飛ばしと同じ（§8 の別課題の候補）

## 5. diff_turn（port の列、`--exes old=直す前 e7f7e32,new`、PYTHONHASHSEED=0、roll 8、max-turns 10、1 コア）

`C:/tmp/ika248/fire_turns.py` は IKA-240 の同名の道具を替えたもの。`tools/diff_turn.run` をそのまま走らせ、ターンごとに判定と、
始めにマジックガードの持ち主が場にいたか（mg）、止まるものが届きうる形だったか（effect: 持ち主がいのちのたまで攻撃技を選んだ、
反動技を選んだ、さめはだ・てつのトゲ・ゴツゴツメットの相手に接触技を選んだ、ステルスロック・まきびしのある側に持ち主が
交代で出る）を記録する。`--inject` は引いた構築ごとに、選出 4 体の 1 体をマジックガード・いのちのたま・反動技（最後の技と
入れ替え）にし、別の 1 体をさめはだかてつのトゲ・ゴツゴツメットにする。`--neutral` は同じ引き・同じ変更で、特性だけを元のまま
にする null 対照（いのちのたま・反動・さめはだはあり、マジックガードだけ無い）。diff_turn に `--jobs` は無い。
